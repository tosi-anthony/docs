The Candidates API lets you create and retrieve candidate profiles stored in Job Dashboard. Use it to sync talent from an external sourcing tool, bulk-import applicants from a third-party job board, or build a custom candidate portal that writes directly to your pipeline. Each candidate record is independent of any particular job — a candidate can be linked to multiple applications across different roles.

---

## List all candidates

Retrieve a paginated list of all candidate profiles in your account.

<ParamField query="tag" type="string">
  Filter candidates by tag. Returns only candidates whose `tags` array contains this value (e.g. `"senior"` or `"sourced"`).
</ParamField>

<ParamField query="limit" type="integer" default="20">
  Number of results to return per page. Maximum: `100`.
</ParamField>

<ParamField query="cursor" type="string">
  Pagination cursor from the previous response's `next_cursor` field. Omit on the first request.
</ParamField>

```bash
curl "https://api.jobdashboard.com/v1/candidates?tag=senior&limit=20" \
  -H "Authorization: Bearer jd_live_xxxxxxxxxxxx"
```

**Response `200 OK`**

<ResponseField name="data" type="array">
  Array of candidate objects.

  <Expandable title="Candidate object fields">
    <ResponseField name="id" type="string">
      Unique identifier for the candidate.
    </ResponseField>
    <ResponseField name="name" type="string">
      Full name of the candidate.
    </ResponseField>
    <ResponseField name="email" type="string">
      Candidate's email address.
    </ResponseField>
    <ResponseField name="phone" type="string">
      Candidate's phone number, or `null` if not provided.
    </ResponseField>
    <ResponseField name="tags" type="array">
      List of string tags applied to this candidate (e.g. `["senior", "backend", "sourced"]`).
    </ResponseField>
    <ResponseField name="created_at" type="string">
      ISO 8601 timestamp of when the candidate profile was created.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="next_cursor" type="string">
  Cursor to pass as the `cursor` parameter on your next request. `null` when no further pages exist.
</ResponseField>

<ResponseField name="has_more" type="boolean">
  `true` if additional pages of results exist beyond this response.
</ResponseField>

## Create a candidate

Add a new candidate profile to your account. If a candidate with the same email address already exists, the API returns a `409 Conflict` response rather than creating a duplicate.

<ParamField body="name" type="string" required>
  Full name of the candidate.
</ParamField>

<ParamField body="email" type="string" required>
  Candidate's email address. Must be a valid email format and unique within your account.
</ParamField>

<ParamField body="phone" type="string">
  Candidate's phone number in any format (e.g. `"+1 415 555 0100"`).
</ParamField>

<ParamField body="linkedin_url" type="string">
  Full URL of the candidate's LinkedIn profile (e.g. `"https://linkedin.com/in/janedoe"`).
</ParamField>

<ParamField body="tags" type="array">
  List of string tags to apply to the candidate. Tags are created automatically if they don't already exist in your account.
</ParamField>

```bash
curl -X POST https://api.jobdashboard.com/v1/candidates \
  -H "Authorization: Bearer jd_live_xxxxxxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Jane Doe",
    "email": "jane.doe@example.com",
    "phone": "+1 415 555 0100",
    "linkedin_url": "https://linkedin.com/in/janedoe",
    "tags": ["senior", "backend", "sourced"]
  }'
```

**Response `201 Created`**

Returns the newly created candidate object. See [Get a candidate](#get-a-candidate) below for the full schema.

<Note>
  Creating a candidate does not automatically link them to a job. To associate a candidate with a specific role, create an application via the [Applications API](/api/applications).
</Note>

## Get a candidate

Retrieve a single candidate profile by its unique ID, including fields not present in the list response such as `linkedin_url` and `notes`.

```bash
curl https://api.jobdashboard.com/v1/candidates/cand_01HXYZ5678ABCD \
  -H "Authorization: Bearer jd_live_xxxxxxxxxxxx"
```

**Response `200 OK`**

<ResponseField name="id" type="string">
  Unique identifier for the candidate.
</ResponseField>

<ResponseField name="name" type="string">
  Full name of the candidate.
</ResponseField>

<ResponseField name="email" type="string">
  Candidate's email address.
</ResponseField>

<ResponseField name="phone" type="string">
  Candidate's phone number, or `null` if not provided.
</ResponseField>

<ResponseField name="linkedin_url" type="string">
  URL of the candidate's LinkedIn profile, or `null` if not provided.
</ResponseField>

<ResponseField name="tags" type="array">
  List of string tags applied to this candidate.
</ResponseField>

<ResponseField name="notes" type="string">
  Free-text internal notes added by your hiring team, or `null` if none exist.
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 timestamp of when the candidate profile was created.
</ResponseField>

<ResponseField name="updated_at" type="string">
  ISO 8601 timestamp of the most recent update to the candidate profile.
</ResponseField>
